What your IT manager will ask — answered

Multi-version directory sign-in

Pick your exact environment: Windows Server 2016/2019/2022, legacy 2012 R2 with NetBIOS binds, Samba 4 AD, or OpenLDAP/FreeIPA. UPN, DOMAIN\user or sAMAccountName — all accepted.

AD groups = Purify roles

Map CN=Purify-Admins and CN=Purify-Operators to admin/operator/viewer. Staff are provisioned and role-synced automatically at login. Local break-glass accounts keep IT un-lockout-able.

Read-only SAP, by construction

The SAP module contains no write path at all. Per-connector entity allow-lists, https enforced, filter shape-checks. Plant-network http only behind an explicit flag on private LANs.

Human-in-the-loop writes

The AI can propose changes; only an approved human decision executes them. Every proposal, decision, login and config change lands in a tamper-evident audit log.

Secrets encrypted at rest

Service-account and connector passwords are Fernet-encrypted under a master key that lives only in the server environment. Empty-password anonymous binds are blocked.

Multi-specialist orchestration

Nine domain specialists (strategy, supply chain, manufacturing, finance, HR, POPIA/legal, IT security…) plus an executive coordinator — on local Ollama, optional cloud hybrids.
